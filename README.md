# Widget Data

Android 1x1 widget that shows mobile data usage in GB since the start of the billing cycle.

## Features

- Reads real system data (same as Android's "Data usage" page)
- Cycle start day configurable from the app
- Multi-language support (Italian, English, Spanish, French, German, Portuguese, Russian, Chinese, Hindi, Turkish, Japanese)
- Transparent widget with white text
- Auto-refresh every 30 minutes
- Works entirely offline and locally — no internet connection required, no data sent anywhere, no servers, no tracking

## How to use

1. Install the APK
2. Open the app once to enable the "Usage access" permission
3. Enter your billing cycle start day and save
4. Add the widget to your home screen

## Requirements

- Android 7.0 (API 24) or higher
- "Usage access" permission enabled

## Privacy

This app does not connect to the internet. It does not collect, store, or transmit any personal data. Everything runs locally on your device.
